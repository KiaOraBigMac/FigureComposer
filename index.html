Image quality and privacy

The original selected files are retained in browser memory and are used as the source for each render. The preview is a separate, reduced rendering and is never used as the export source. Images are not uploaded by this page.

TIFF files are decoded to 8-bit RGBA for drawing in Canvas. This means this version does not preserve 16-bit TIFF precision, scientific metadata, or all special channels. Use the original file if those properties are essential.
